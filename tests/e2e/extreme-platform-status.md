## Decisiones técnicas y límites

- ATE determinista permanece separado de IA: `--scenarios` no construye modelo; generación `--request` cachea el plan validado, y el resultado de navegador no se cachea. No invocar Gemini fue intencional en este corte.
- La protección existente no se debilitará para satisfacer misiones. La app bajo prueba usa identidad y configuración sintéticas; Admin SDK se limita a preparar/restablecer UID reservados en Emulator, mientras las acciones funcionales y permisos se verifican desde UI/SDK cliente.
- El almacenamiento de cuota es agregado, no persiste prompts/secrets; no se ha validado coordinación atómica entre procesos separados que compartan el archivo de uso. El cap de coste se calcula con tokens estimados antes de llamada y metadatos reales después; una respuesta podría superar el cap si la salida excede la estimación. La reserva estimada sí se comparte entre llamadas concurrentes dentro del mismo gestor.
- La configuración `.env` de Agentic Test Explorer no se leyó ni se copiará a reportes/artefactos.
